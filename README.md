# Brushless Motor Controller R&D
The brushless moco is an electrical board that will simplify the electrical system within the brushless arm. This doesn't only include the brushless arm but also everything else that will use a significantly large brushless motors. This project provides future use cases for both **drivetrain** and **brushless arm** going forth.
